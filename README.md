# CHAINVISION

CHAINVISION is an integrated supply chain intelligence platform that connects demand sensing & replenishment planning (P1) with autonomous procure-to-pay (PR2) into a single end-to-end flow. See [`00_PROJECT_CONTEXT.md`](./Documentaion/00_PROJECT_CONTEXT.md) for the full project context, architecture, schema, and build plan — that document is the single source of truth for this repository.
